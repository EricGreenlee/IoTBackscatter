# IoTBackscatter
Backscatter hardware, firmware, and modem software for collecting, transmitting, and demodulating environmental data from backscatter tags. Work in progress as of April 2, 2026.

## Project overview
This project aims to explore how effective backscatter communications can be for communicating data from IoT sensors, specifically in the environmental sensing domain. It uses CDMA to spread packets out over time, allowing for extended range by allowing the receiver to see further into the noise floor and extended scalability by allowing synchronization-free channel sharing from multiple IoT sensors simultaneously. IoTBackscatter focuses on use cases where a single location has dedicated power and wired Internet access, meaning that the backscatter communication uses a monostatic paradigm that limits the range compared to that advertised with many conventional projects.
